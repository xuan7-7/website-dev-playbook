# 故障速查流

1. 一句话描述：页面/宽度/主题/操作。
2. 按 `references/symptom-table.md` 定位根因，只改对应点。
3. 单点修复，立即验证该现象是否消失。
4. 回归相邻功能（导航、暗色、移动端）。
5. 未命中先停，收集证据（截图/控制台/DOM/构建日志）再分析，不连环试错。

边界：遵守总纲 §8；一次只改一处。
