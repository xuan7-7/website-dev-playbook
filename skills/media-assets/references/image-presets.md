# 图片尺寸/质量/体积对照

| 用途 | 长边 | 质量 | 目标体积 |
|---|---|---|---|
| 全屏背景（桌面） | 1600–1920 | 70–78 | ≤50KB |
| 全屏背景（手机） | 900–1200 | 70–75 | ≤35KB |
| Hero 插画 | 1200–1600 | 72–80 | ≤80KB |
| 卡片/列表图 | 800–1200 | 72–78 | ≤40KB |
| 缩略图 | 600 | 70–75 | ≤25KB |
| 头像 | ≤200 | 75–82 | ≤10KB |
| favicon | 32/180 | png/svg | ≤5KB |

## 说明

- 以上为参考值，按页面实际显示尺寸与网络条件调整
- 透明图用 WebP alpha；半透明渐隐会比不透明略大
- 同一张图不要同时导出多个超大尺寸；按断点给 2–3 档即可
- 字体子集：只保留站点实际用字 + 常用标点 + ASCII；换字体/加新内容后重跑
