# 溢出「⋯」算法与边界

## 算法

1. 先把所有标签放回主容器，记录每个标签宽度。
2. `可用宽度 = 容器宽 - 视图切换宽 - 间距`；若需要「⋯」，再预留其宽度。
3. 从左往右累加，放不下的进溢出列表；溢出列表非空才显示「⋯」。
4. 「⋯」点击后把溢出标签移入独立行容器（`hidden` 切换），点击外部/选择后收起。
5. `resize` 防抖 150ms 重算；主题/字体加载完成后也重算一次。

## 边界

- 单个标签比容器还宽：允许横向截断或临时让其独占一行，不要死循环
- 全部放得下：隐藏「⋯」并清空溢出行
- 用户已选中溢出里的分类：展开行要保持选中态，不要重置
- 键盘：Tab 能到「⋯」和溢出项；Esc 收起
- 首屏无 JS 时：退化为可横向滚动或换行，不能让内容消失
