# 线上验证步骤

1. 确认 CI 部署成功（日志最后一步 success）。
2. 逐页查状态码（4 个关键页）：`curl -4 -s -o /dev/null -w "%{http_code}" <url>`，期望 200；HTTPS 偶发失败重试一次。
3. 关键元素存在性：导航、页脚、列表条目、详情标题。
4. **禁用缓存**强刷后验证：
   - 本次改动对应的 CSS/规则真的存在（核对 hash 或规则文本，不能只看"页面变好看了"）
   - 暗色切换正常且刷新保持
   - 移动端头部单行、点空白收起
5. 控制台无报错、无非预期 404 请求。
6. 给用户线上地址 + 一行验证结论（状态码、关键元素、截图），不说"应该好了"。

注意：不要在用户确认预览前推送；CDN 可能短时返回旧资源，禁用缓存验证是必要步骤。
