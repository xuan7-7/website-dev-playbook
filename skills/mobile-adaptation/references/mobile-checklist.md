# 移动端检查清单

## 布局
- [ ] 390px、320px 无横向滚动
- [ ] 长标题/长单词不撑破容器（`overflow-wrap`）
- [ ] 固定头部不遮挡锚点/内容
- [ ] 图片按容器缩放，不变形

## 交互
- [ ] 触控目标 ≥44×44px
- [ ] 抽屉/面板打开时锁滚动，关闭恢复
- [ ] 点空白与 Esc 能收起
- [ ] 依赖 hover 的操作有触屏替代

## 内容
- [ ] 列表只保留核心信息，次要内容可折叠
- [ ] 表格/代码块可横向滚动而不是撑破页面
- [ ] 字体不小于 12px，正文 14–16px

## 验证
- [ ] 390 / 320 / 768 截图
- [ ] 真机或模拟器点一遍主流程
- [ ] 无 console 报错
