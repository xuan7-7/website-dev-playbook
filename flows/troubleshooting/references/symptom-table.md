# 症状对照表

| 现象 | 根因 | 修法 | 通用性 |
|---|---|---|---|
| 子路径下 CSS/图片 404 | 绝对路径 | 全站 `url()` | 通用（子路径部署） |
| 页面偏右、横向滚动 | 全宽出血（`w-screen` + 负 margin/translate） | 去掉 bleed，容器内约束 | 通用 |
| 动态 class 不生效 | 运行期字符串不被编译 | 改固定 CSS 类 | 栈相关（Tailwind） |
| 暗色选中态看不见 | 通用 `!important` 压过状态类 | 状态类也 `!important` | 通用（机制） |
| 列表/导航处空黑块 | 条件渲染留下空 div | 空项不渲染，单列占满 | 通用 |
| 导航暗色下看不清 | 硬编码深色点/边框 | 用 `currentColor` + 暗色变量 | 通用 |
| 手机头部换行 | 标签+控件同排超宽 | 控件仅图标、溢出收「⋯」 | 通用 |
| 点击面板外不收起 | 缺 outside-click | document 委托 + closest | 通用 |
| 字体缺字变豆腐块 | 子集没包含新字 | 重新生成子集 | 通用 |
| 页面出现占位/待开放 | 需求未完成就写文案 | 静默隐藏，只留访客向提示 | 通用（内容规范） |
| 图片发虚/被裁切 | 未按断点设尺寸/取景 | 宽高比 + 分断点 `object-position` | 通用 |
| 主题切换闪白 | 首屏未内联主题脚本 | 渲染前读 localStorage 设 data-theme | 通用 |
| 路径判断失效/某区样式不生效 | pathname 含 base，startsWith 匹配失败 | 先剥 base 再匹配 | 通用（子路径） |
| 线上仍是旧样式/旧脚本 | CDN 或浏览器缓存 | 禁用缓存验证 + 核对 CSS hash/规则 | 通用 |
