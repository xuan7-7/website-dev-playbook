# 决策选择题流

1. 把要定的事压缩成一个问题。
2. 给 2–4 个 A/B/C：是什么、优点、代价、适合场景；推荐项写理由。
3. 固定加「其他：______（自由补充）」。
4. 可写默认建议，但仍等用户确认。
5. 用户选后记录进 brief/决策记录，并回执"按 X 执行"。

模板 `assets/options-template.md`；示例 `references/examples.md`。边界：遵守总纲 §8。
