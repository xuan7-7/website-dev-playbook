# 暗色检查清单

## 覆盖范围

- [ ] 导航、页脚、标签、按钮、输入框
- [ ] 表格、代码块、图表、公式
- [ ] 空状态、404、错误页、移动端菜单
- [ ] 选中态、焦点环、禁用态
- [ ] 图片/插画背景上的文字

## 颜色 token

语义命名而非色值命名：`--color-ink`（正文）、`--color-ink-2`（次要）、`--color-ink-3`（辅助）、`--color-ink-4`（弱化）、`--color-bg`、`--color-card`、`--color-border`。

- 亮色：深字浅底；暗色：浅字深底，背景不要纯黑（#121016 ~ #1c1926 区间）
- 状态色（成功/警告/危险/强调）在暗色下至少提亮一档
- 半透明白卡（`bg-white/85`）在暗色下改深色实底或降低不透明度

## 常见反模式

- 只改背景不改边框，控件轮廓消失
- 全局 `!important` 重置背景，压掉状态色
- 用纯白文字配深灰底，对比够但刺眼（用 #ece7f5 一类）
