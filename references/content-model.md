# 内容模型与导航约定

## frontmatter 字段（静态博客参考）

| 字段 | 类型 | 必填 | 默认/说明 |
|---|---|---|---|
| title | string | 是 | 标题 |
| date | date | 是 | 排序与显示 |
| category | enum | 是 | 分类；给默认分类避免漏填 |
| chapter | string | 否 | 章节标签；`.default('')` |
| summary | string | 否 | 列表摘要；`.default('')` |
| order | number | 否 | 分类内排序 |
| tags | string[] | 否 | 标签 |
| cover | string | 否 | 封面图 |

原则：**可选字段全部给默认值**，新增内容不因缺字段破构建；必填字段在 schema 里校验。

## 分类内独立编号

- 按分类分组、按 order/date 排序后生成索引，统一 `padStart(2, '0')` 显示「第 01 话」
- 列表、详情、归档、标签全部复用同一个索引函数，不各页各算
- 分类字段是 enum 时，新分类要同步列表与默认值

## 上一篇 / 下一篇

- 只在**同分类**内取前后项；缺项不渲染占位元素（避免空 div 黑块）
- 只有一项时单列占满，不留空格
- 链接用 `url()` 拼接 base

## 列表与状态

- 视图（列表/宫格）写 localStorage，刷新保持；首次默认一种
- 分类深链：`?cat=<分类>` 初始化选中分类；非法值回落默认
- 空状态统一访客向文案（如「还没有该类型记录。」），不写开发说明

## 验收

- 新增内容只填必填字段也能构建
- 编号在列表/详情/归档/标签一致
- 首篇/末篇无空占位；单列时卡片占满
- 刷新后视图与分类保持
