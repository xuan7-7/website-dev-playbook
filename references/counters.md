# 第三方计数器集成规范

以外部统计脚本（如 VerCount）为例，以下为实测过的约束。

## 唯一 ID

- 计数用的 `id`（如 `vercount_value_site_pv`）全站只能有一份真源，放在页脚
- 其他页面需要显示时，用 `data-*` 占位 + 脚本复制数据，**不要复制同一 id**；重复 id 会取到错误节点或渲染异常
- 修改前先扫一遍全站 id 是否唯一

## 加载与失败

- 脚本 `async` 引入，放在 body 末尾或 `defer`，不能阻塞渲染
- 失败时只应导致数字空白，不能让页面报错或布局塌陷；回调里做空值保护
- 首载可能较慢（实测 7–13 秒，受外部 CDN 影响），需要的话给占位符而不是 0 误解

## 计数口径

- 计数按站点域名/host 统计，本地预览与线上是两套；上线首日从 0 开始属正常
- 隐藏计数位（如页脚小字）不影响脚本运行，但不要把隐藏元素当唯一 id 源

## 验收

- 全站无重复计数 id
- 断网/脚本失败时页面正常，仅数字空白
- 线上数字正常增长，本地不污染线上
