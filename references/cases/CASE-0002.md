# 移动端页面偏移/横向滚动（hero 溢出）
- ID: CASE-0002
- 现象: 手机上内容整体偏右、可左右拖动，桌面正常
- 触发条件: hero 用 `left-1/2 w-screen -translate-x-1/2` 做全宽出血
- 根因: 视口宽度在移动端含滚动条/浏览器栏，`w-screen` 超出容器导致横向溢出
- 修法: 去掉 bleed 类，在容器内约束宽度；需要全宽时用 `w-full` + 外层 overflow
- 状态: 已修复
- 回归检查: 390px 无横向滚动条；`document.documentElement.scrollWidth === clientWidth`
- 通用条目: skills/troubleshooting 症状表；总纲阶段 E
