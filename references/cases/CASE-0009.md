# 页面过重、首屏加载慢
- ID: CASE-0009
- 现象: 首次打开 20 秒级，页面总重 600KB+
- 触发条件: 首屏大图未压缩、未转 WebP、字体未子集
- 根因: 原始素材直接上线
- 修法: 图片转 WebP + 限尺寸（背景 ≤50KB）；字体子集化；首屏图 preload；总重目标 ≤400KB
- 证据: 优化前后字节对比（602KB→197KB 量级）
- 状态: 已修复
- 回归检查: 页面总重、首屏图、字体积均达标（flows/performance 预算表）
- 通用条目: flows/media-assets 执行流 1–4；flows/performance
