# 子路径部署后样式/图片 404
- ID: CASE-0001
- 技术栈: Astro + GitHub Pages 子路径
- 现象: 线上页面无样式、图片裂开；本地正常
- 触发条件: `base: '/<repo>'` 部署，资源用绝对路径 `/assets/...`
- 根因: 浏览器按站点根解析 `/assets`，子路径下指向错误位置
- 修法: 统一 `url()` 拼接 base（见 `references/scaffold.md`），全站替换硬编码路径
- 证据: 线上 404 请求路径与 dist 目录对比
- 状态: 已修复
- 回归检查: 构建后子路径下所有链接可访问；部署后强刷无 404
- 通用条目: skills/deployment 执行流 1；skills/troubleshooting 症状表
