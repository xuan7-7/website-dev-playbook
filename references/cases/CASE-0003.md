# 运行期拼的 Tailwind class 不生效
- ID: CASE-0003
- 技术栈: Tailwind 4
- 现象: JS 里 `classList.toggle('bg-[#2b2333]')` 点击无变化
- 根因: Tailwind 在构建期扫描源码生成类；运行期字符串不在扫描范围内
- 修法: 改为固定 CSS 类（如 `.is-active`）并在样式表里定义；或把 class 写进模板
- 状态: 已修复
- 回归检查: 点击后 computed style 变化；构建产物里存在该 CSS 规则
- 通用条目: references/scaffold.md「样式工程注意」
